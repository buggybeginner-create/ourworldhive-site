SETUP GUIDE (STEP BY STEP)

WHICH DATA SOURCE IS BEST?

Angel One SmartAPI (recommended): free, real-time, gives all 50 stocks in one call, and logs in by itself every day with TOTP. Needs a free Angel One demat account.

ICICI Breeze: free for ICICI Direct customers. One stock per call (100 calls a minute, 5,000 a day), so Nifty Pulse shows only your chosen stocks (max 20) and refreshes every 15–90 sec. You log in once every morning with ICICI DAILY LOGIN.

Yahoo (built in): no account, unofficial, can be a little delayed. Used automatically when Angel One is not set up.

STEP 1 · ANGEL ONE API KEY
  1. Open a free Angel One account (if you don't have one).
  2. Go to smartapi.angelone.in → Sign up / Login → Create an App. Type: Market Feeds API. Redirect URL: https://ourworldhive.com.
  3. Copy the API Key.
  4. Open smartapi.angelone.in/enable-totp, enter client ID + MPIN + OTP. Copy the secret text shown under the QR code (scan the QR in Google Authenticator too).
STEP 2 · CREATE THE CLOUDFLARE WORKER
  1. dash.cloudflare.com → Workers & Pages → Create → Create Worker. Name: nifty-pulse → Deploy.
  2. Edit code → delete everything → paste the file nifty-pulse-worker.js → Deploy.
  3. Your link looks like https://nifty-pulse.YOURNAME.workers.dev. Open /quotes on it: you should already see Yahoo data.
STEP 3 · ADD YOUR SECRETS
  1. Worker → Settings → Variables and Secrets → Add, type Secret:
  2. ANGEL_API_KEY, ANGEL_CLIENT (client code), ANGEL_PIN (MPIN), ANGEL_TOTP_SECRET (secret text from step 1), ADMIN_KEY (any long password you make up).
  3. Deploy. Open /status: it should say "angel": true. Open /quotes: "src": "angel".
STEP 3B · ICICI BREEZE (OPTIONAL)
  1. Log in at api.icicidirect.com/apiuser/home → Register an App. Redirect URL: https://nifty-pulse.YOURNAME.workers.dev/breeze/callback.
  2. Copy the API Key and Secret Key. Worker → Settings → add secrets BREEZE_API_KEY and BREEZE_SECRET.
  3. Create the KV namespace and binding NP (see step 5, point 4). Breeze needs it to keep the day's login.
  4. In this app: Data source → ICICI BREEZE → CHOOSE BREEZE STOCKS → ICICI DAILY LOGIN every morning before 9:15.
STEP 4 · CONNECT THIS APP
  1. Paste the worker link in Worker link above → SAVE & TEST.
  2. Owner key: type your ADMIN_KEY → SAVE. Only then Angel One and ICICI Breeze open (visitors always get Yahoo).
  3. The pill at the top turns LIVE in market hours.
STEP 5 · TELEGRAM ALERTS (OPTIONAL)
  1. In Telegram open @BotFather → /newbot → copy the bot token.
  2. Send any message to your new bot, then open https://api.telegram.org/bot<TOKEN>/getUpdates and copy "chat":{"id": …}.
  3. Worker → Settings → add secrets TG_BOT_TOKEN and TG_CHAT_ID.
  4. Workers & Pages → KV → Create namespace nifty-pulse. Worker → Settings → Bindings → KV namespace, variable name NP.
  5. Worker → Settings → Trigger events → Cron: * 3-10 * * 1-5.
  6. Alerts tab → type your Admin key → SEND MY ALERTS TO TELEGRAM → TEST.
