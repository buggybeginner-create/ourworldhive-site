Help

Type a calculation on each row: 1200 + 300. Type a name before it: Rent 5000 + 300.
Excel style: =SUM(A1:A5), =ROUND(A3*1.18,2), =IF(A2>100,1,0). Use =SUM(ABOVE) to add all rows above.
Percent: 200 + 10% gives 220. 10% of 500 gives 50.
Names: price = 250 then price * 3.
Header: start the row with #. Note: start with //.
Rows that start with = or have a name = are not counted in TOTAL.
While typing a formula, start with = and the available formulas show above the keys (type =s to see SUM, SUMIF…). Tap another row's number or value to link that cell (A1, A2…).
Tap ↗ Ref to pick any row, name, template or formula. Your templates also work inside formulas, like =MOTOR_CURRENT(415,15,0.85). The Calc tab accepts the same formulas and rows (A1, A2…).
