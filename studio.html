This account is not the owner

Studio could not make this account the owner automatically. Check that you signed in with the owner Google account and that the new rules are published. Or do this once by hand in Firebase:

1. Open Firebase, then Firestore Database, then the Data tab.
2. Tap Start collection (or open the roles collection if it exists).
3. Collection ID: roles. Document ID: paste the code below.
4. Add one field: name role, type string, value admin. Save.

Who can edit this website

The owner account is always allowed. You can add more Google accounts. They sign in at studio.html with that Google account and get the same powers: edit pages, gallery, buttons and settings, and moderate the forum.

Backup

Download a copy of everything you made here (posts, reviews, gallery entries, marketplace items, settings). Keep it somewhere safe.

Other tools

Forum moderation and medals are in the forum, under Moderation, then Team. Visitor numbers, login accounts and the raw database are in the Firebase console.
